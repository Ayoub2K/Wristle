# Wristle

A voice-first Claude assistant for the Samsung Galaxy Watch 4 (Wear OS), talking directly to the Claude API — no phone or PC required.

**Status:** planning. No code yet.

## Roadmap

- **Phase 1:** standalone Claude on the Watch 4, based on [mushinlab/claude-watch](https://github.com/mushinlab/claude-watch) (MIT).
- **Phase 2 (later):** remote control of a computer (macOS, Windows, Linux) from the watch.

## Security

Never commit API keys. Local secrets go in `local.properties` or a `.env` file, both of which are git-ignored.
